## Decision boundary

This register deliberately preserves alerts with no reported first patched
version as unresolved. It does not use an override, suppress an audit gate, or
infer that a clean audit of another revision closes a Dependabot alert. Owner
and supervisor work are distinct: backend prepares compatibility changes;
the supervisor runs exact-candidate validation and performs the authoritative
alert-state recheck.
